# ⌨ 上下文快捷键审校台（Node.js + React）

为快捷键体系建立**上下文树**，给命令指定「作用上下文」与 **1～3 次按键**组成的序列；
选中任一上下文后，系统按**最近祖先规则**构建生效绑定，自动审校两类冲突，并支持**逐键模拟**。

## 一条命令启动（Docker）

```bash
docker compose up --build -d
```

启动后访问：

> **http://localhost:3000**

端口为 **3000**（API 与页面同端口；数据持久化在 Docker 卷 `shortcut-data` 中）。
停止：`docker compose down`；连同数据一起清除：`docker compose down -v`。

> 不想用 Docker？一条命令跑开发模式（自动安装依赖、前后端同时启动）：
>
> ```bash
> npm install && npm run dev
> ```
>
> 然后打开 http://localhost:5173 （Vite，`/api` 已代理到后端 3000）。
>
> 生产方式（本机）：`npm install && npm run build && npm start`，访问 http://localhost:3000

## 功能说明

### 1. 上下文树

- 左侧树面板可新建 / 重命名 / 删除上下文（删除会一并移除子树与其中命令）。
- 每个上下文是一个快捷键作用域，如：`全局 / 编辑器 / 文本编辑`、`全局 / 终端`。

### 2. 命令与按键序列

- 命令包含：名称、**所属上下文**、按键序列。
- 序列由 **1～3 次按键**组成，多次按键用空格分隔：
  - `ctrl+s`、`g d`、`ctrl+k ctrl+t`、`f2`、`' d`
  - 修饰键：`ctrl / alt / shift / meta`（`cmd`、`win` 同义），大小写不敏感。
- 在「命令定义」面板点击录制框后**直接按下快捷键**即可录入，`Backspace` 删除末键。

### 3. 最近祖先生效规则

选中某上下文后，生效绑定 = 从根到该上下文**祖先链**上的全部命令：

- 同一序列以**最靠近选中上下文**的定义为准（子级覆盖祖先）；
- 被覆盖的祖先命令在「被后代覆盖的祖先绑定」中灰色列出，并标明被谁覆盖；
- 祖先链之外（兄弟分支）的命令不生效。

### 4. 冲突审校（双方来源 + 最短触发输入）

| 冲突类型 | 判定 | 展示 |
| --- | --- | --- |
| **同层序列冲突** | 同一上下文中多条命令绑定到完全相同的序列 | 所有同名命令、来源路径与深度、最短触发输入（即该序列） |
| **前缀冲突** | 生效绑定中序列 A 是序列 B 的严格前缀（如 `g` 与 `g d`，跨祖先也检测） | 双方命令与来源路径；短序列为「立即触发方」，长序列为「等待后续键」；**最短触发输入 = 前缀序列** |

> 设计取舍：子级用相同序列覆盖祖先属于**有意遮蔽**，不算冲突，只在覆盖区展示；
> 前缀关系则一律报出——按下短序列时其命令已可立即触发，长序列必然多等一拍。

### 5. 逐键模拟器

- 点击模拟捕获区后逐键输入，实时显示三种状态：
  - **已触发**：缓冲与某生效绑定完全一致，给出命中命令与来源（多命令同时命中显示歧义）；
  - **等待后续按键**：列出所有以当前输入为前缀的候选命令，并高亮「还需按下的键」；
  - **无匹配**：没有绑定以当前输入开头，下一次按键自动作为新序列的开始。
- `Backspace` 回退末键，`Esc` 清空；触发完成后再按键自动开启新一轮输入。

### 6. 初始演示数据

首次启动自动载入一套覆盖全部场景的数据，在左侧选择 **`全局 / 编辑器 / 文本编辑`** 即可同时看到：

- 同层冲突：`删除整行` 与 `添加/取消书签` 均为 `ctrl+d`；
- 前缀冲突：`全局 g` 与 `编辑器 g d`、文本编辑下 `'` 与 `' d`；
- 子级覆盖：文本编辑的 `alt+d` 覆盖全局 `alt+d`。

顶栏「↺ 重置演示数据」可随时还原。

## 技术结构

```
.
├── Dockerfile                # 多阶段：npm install + vite build → node 运行
├── docker-compose.yml        # 单服务，3000 端口 + 数据卷
├── server/
│   ├── index.js              # Express API + 生产环境托管 dist/
│   ├── resolve.js            # 最近祖先解析 + 同层/前缀冲突检测（核心算法）
│   ├── store.js              # JSON 文件持久化（data/state.json）
│   └── seed.js               # 演示数据
├── shared/
│   └── key.js                # 前后端共用的按键规范化
└── src/                      # React 前端（Vite）
    ├── App.jsx               # 布局与数据流
    ├── ContextTree.jsx       # 上下文树
    ├── CommandManager.jsx    # 命令增改删 / 按键录制
    ├── Panels.jsx            # 生效绑定 + 冲突审校
    ├── Simulator.jsx         # 逐键模拟器
    ├── ui.jsx                # 键位徽章、按键捕获框
    └── keyEvent.js           # 浏览器 keydown → 规范化 token
```

### 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 全部上下文与命令 |
| GET | `/api/resolve/:contextId` | 生效绑定 / 覆盖 / 冲突（含双方来源、最短触发输入） |
| POST/PATCH/DELETE | `/api/contexts...` | 上下文增改删 |
| POST/PUT/DELETE | `/api/commands...` | 命令增改删（序列写入时统一规范化并校验 1～3 键） |
| POST | `/api/reset` | 还原演示数据 |

健康检查：`GET /api/health`。
